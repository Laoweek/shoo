# Decision model calibration harness

Measures how well a Decision model and request shape judge Tiles against Rules, on a fixed labelled set. The default request is byte for byte what `src/engine/decisions.ts` sends (`requests.test.ts` checks this), so a run with no variant flags measures the shipped engine. The engine itself is not touched.

All data is synthetic: no video IDs, no URLs. Scripts never print or write the API key. They read `OPENROUTER_API_KEY` from `.env.local` (or `--env <file>`). Live runs spend OpenRouter credit on that key, within the `--cap` you set.

The results behind the shipped Filtering strength presets are summarised in `docs/spec/decision-engine.md` Section 2.3.

## Files

| Path | What |
|---|---|
| `test/calibration/tiles.json` | 525 synthetic Tiles `{ id, title, channel, durationSec, surface, isShort, lang, category, hardNegative, notes }`. `hardNegative` names the Rule a Tile was written to resemble without matching (author intent, not a label). Shorts have no channel or duration, as on the Shorts shelf |
| `test/calibration/rules.json` | Rule sets A (Topic starter rules), B (realistic 10-rule set), C (2 Topic Keep rules), D (3 Thumbnail rules), E (A with the Crypto rule R3 meant as get-rich-quick hype only) |
| `test/calibration/labellers/labeller{1,2}.json` | Two blind, independent labellings of every Tile against B and C |
| `test/calibration/labellers/getrich-labeller{1,2}.json` | Two more blind labellings of every Tile for E's R3: `{ id, match, unsure? }` against the hype-only definition in `labels.json` `_doc` |
| `test/calibration/labels.json` | Merged gold labels, agreement (Cohen's kappa) and counts. Built by `merge-labels.mjs` |
| `test/calibration/thumbnails.json` | Labels of the 32 synthetic 320x180 thumbnails for rule set D, by construction. Written by `make-thumbnails.mjs` |
| `test/calibration/thumbnails/*.jpg` | The thumbnail images. Generated by `make-thumbnails.mjs` and git-ignored, so run it once before a thumbnail run |
| `test/calibration/runs/<experiment>.jsonl` | Git-ignored, created on the first run. One log per run: a `meta` line (config, route, price, key usage), one `request` line per HTTP attempt (model, provider, status, latency, `usage.input_tokens`, `usage.cost`, decoded per-Tile answers), `skipped` lines when the budget guard stops, and an `end` line |
| `lib.mjs` | Request builders, decoding, network, budget guard |
| `run.mjs` | Runs one experiment |
| `evaluate.mjs` | Metrics from one or more run logs |
| `models.mjs` | Lists decision models, provider tags and prices (free, public catalogue) |

## Labels

Each Tile was labelled twice by two independent language-model labellers that saw only the Tile facts and the Rule texts, not the author's notes or each other's work. Merge (`node scripts/calibration/merge-labels.mjs`): both say no Rule gives keep. Both name Rules with at least one in common gives remove, with `removeAll` = the shared Rules (any of them counts as correct attribution). Anything else is `ambiguous: true`: kept in the file, left out of headline metrics, reported apart. Rule set A labels are the B labels mapped through `rules.json` `A.sameAsB` (the texts are identical). Keep labels merge the same way into `keep`, `keepAll`, `keepAmbiguous`. Rule set E labels are each labeller's A refs with R3 replaced by the matching hype-only answer, merged the same way. `E.unsure` marks Tiles a labeller was unsure about (counted as answered).

Rule set A has 4 Rules, not 5: the fifth starter, "Shorts", is an Exact rule (kind `short`) that Shoo matches locally and never sends to the model.

Both labellers are language models of the same family, so their agreement overstates what two people would reach. Treat absolute numbers as optimistic and comparisons between runs as the finding.

## Running

Every live run needs `--experiment <name>` (the log file name, never overwritten unless `--force`) and `--cap <usd>`. The budget guard estimates each request's cost before sending it and stops the run when the sum of spent, in-flight and next would pass the cap. The first request runs alone to learn the real cost per character. Remaining requests are logged as `skipped`. An attempt without `usage.cost` (a timeout, or a model that leaves it out) is booked at input tokens x price, or at its estimate. Requests time out after 15 s, retry once on 429, 5xx, network error or timeout (after the Retry-After header up to 10 s, else 2 s; a longer Retry-After ends the request), and run at most 4 in flight (`--concurrency`, default 4).

A 200 response that the shipped `validateResponse` would reject (choice not an option, unknown probability keys, probabilities not summing to 1, missing answers or usage) is logged with `rejected`, and all its Tiles count as invalid, as in the engine.

Add `--dry-run` to any command to see the batches, question count, a sample body and a rough cost (2.4 characters per token, measured on clef-flash) without calling the Decisions API. Dry runs and live runs read the provider tag and price from OpenRouter's public endpoints list.

Options:

| Option | Default | Meaning |
|---|---|---|
| `--model <slug>` | `cloudflare/clef-flash` | Decision model |
| `--provider <tag>` | known tag, or the only endpoint | Provider pin (`order: [tag]`, `allow_fallbacks: false`, `data_collection: "deny"`). `models.mjs` lists tags. The harness pins the endpoint's real tag. The shipped `providerFor` pins the slug prefix for models it does not know (for example `microsoft` where the endpoint tag is `azure`), so a new model needs an entry in `PROVIDER_TAGS` in `src/engine/decisions.ts` before it can ship |
| `--rules A\|B\|D\|E` | `B` (text), `D` (thumbnail) | Rule set |
| `--rule-text <ref>=<text>` | none | Sends another wording for one Rule of the set (repeatable). The labels stay the set's. The log's `config.ruleTexts` records the texts sent |
| `--keep none\|C\|C:K1` | `none` | Topic Keep rules, asked as `tNN_<ref>` nouls |
| `--framing choice\|noul` | `choice` | `noul` = one question per Tile and Rule with the Rule text inline (`docs/spec/decision-engine.md` §2.4) |
| `--criteria text\|null` | `text` | Choice criteria values |
| `--task shipped\|noKept\|viewer\|strict` | `shipped` | Choice task wording (`lib.mjs` `CHOICE_TASKS`). `--task-text "<text>"` sends any other wording |
| `--noul-task`, `--keep-task` | `shipped` | `shipped`, `viewer`, `about` (`lib.mjs` `NOUL_TASKS`) or a template with `{rule}` |
| `--fields` | text: `title,channel,duration,surface`, thumbnail: `title,channel` | Tile facts sent. The text pass always sends the title. The thumbnail pass sends only the image with `--fields none` |
| `--batch <n>` | shipped size | Tiles per request, refused above 64 questions |
| `--tiles 1-32`, `--ids c001,c002`, `--where lang=ja,de` | all | Selection, in file order. `--where` repeats and matches any listed value |
| `--seed <n>` | none | Shuffle the selection before batching |
| `--pass text\|thumbnail` | `text` | Thumbnail pass sends one request per image (`docs/spec/decision-engine.md` §4) |

### Commands

Validation run on 32 Tiles:

```sh
node scripts/calibration/run.mjs --experiment validate-clef-flash-B-32 --rules B --tiles 1-32 --cap 0.005
node scripts/calibration/evaluate.mjs test/calibration/runs/validate-clef-flash-B-32.jsonl
```

Shipped shape on the full set (about $0.008 without Keep rules, about $0.012 with C at the October 2026 price of $0.038 per M tokens):

```sh
node scripts/calibration/run.mjs --experiment clef-B --rules B --cap 0.03
node scripts/calibration/run.mjs --experiment clef-B-keepC --rules B --keep C --cap 0.04
node scripts/calibration/run.mjs --experiment clef-A --rules A --cap 0.03
```

Model sweep (check `node scripts/calibration/models.mjs` first; models that bill the state once per question, such as Liquid and Perplexity, cost more per Tile than their price suggests, so keep the cap):

```sh
for m in cloudflare/clef-flash cloudflare/clef cloudflare/clef-omni liquid/d1 perplexity/pplx-decider-v1.1-27b \
         typesafe/jev-1.13 microsoft/microsoft-decision-1 nace-ai/drex-v1.5 respan/span-01 inception/mercury-decide; do
  node scripts/calibration/run.mjs --experiment "sweep-$(echo $m | tr / _)" --model "$m" --rules B --keep C --cap 0.15
done
# Models with several endpoints need --provider, e.g. --model upstage/solar-decide --provider upstage
node scripts/calibration/evaluate.mjs test/calibration/runs/sweep-*.jsonl --brief
```

Prompt variants (clef-flash, rule set B; same Tiles and batches in every run):

```sh
node scripts/calibration/run.mjs --experiment var-shipped     --rules B --cap 0.03
node scripts/calibration/run.mjs --experiment var-noKept      --rules B --task noKept --cap 0.03

node scripts/calibration/run.mjs --experiment var-noul        --rules B --framing noul --cap 0.10
node scripts/calibration/run.mjs --experiment var-title-only  --rules B --fields title --cap 0.03
node scripts/calibration/run.mjs --experiment var-no-surface  --rules B --fields title,channel,duration --cap 0.03
node scripts/calibration/run.mjs --experiment var-batch1      --rules B --batch 1 --concurrency 4 --cap 0.05
node scripts/calibration/run.mjs --experiment var-batch8      --rules B --batch 8 --cap 0.03
node scripts/calibration/run.mjs --experiment var-seed2       --rules B --seed 2 --cap 0.03
node scripts/calibration/evaluate.mjs test/calibration/runs/var-*.jsonl --brief
```

Keep question variants:

```sh
node scripts/calibration/run.mjs --experiment keep-shipped --rules B --keep C --cap 0.04
node scripts/calibration/run.mjs --experiment keep-viewer  --rules B --keep C --keep-task viewer --cap 0.04
```

Thumbnails (rule set D, 32 images, about $0.001 per run on clef-flash):

```sh

node scripts/calibration/run.mjs --experiment thumb-clef --pass thumbnail --cap 0.01
node scripts/calibration/run.mjs --experiment thumb-clef-image-only --pass thumbnail --fields none --cap 0.01
node scripts/calibration/run.mjs --experiment thumb-pplx --pass thumbnail --model perplexity/pplx-decider-v1.1-27b --cap 0.01
node scripts/calibration/evaluate.mjs test/calibration/runs/thumb-*.jsonl
```

Rule wording on rule set E, whose R3 labels mean "get-rich-quick hype only" (about $0.005 per run without Keep rules):

```sh
node scripts/calibration/run.mjs --experiment hype-E-current --rules E --cap 0.01
node scripts/calibration/run.mjs --experiment hype-E-K1 --rules E --rule-text "R3=Get-rich-quick hype: crypto pumps, trading wins and side hustles that promise fast money" --cap 0.01
node scripts/calibration/evaluate.mjs test/calibration/runs/hype-E-*.jsonl --cutoffs 0.9,0.75,0.55
```

Slices by another Tile field: `evaluate.mjs <log> --by category`. Machine-readable metrics: `--json <out.json>`. Other preset cutoffs: `--cutoffs <cautious>,<balanced>,<eager>`.

Harness checks (no network): `pnpm exec vitest run --project unit scripts/calibration`.

## Metrics

`evaluate.mjs` reports, overall and per slice (surface, language, hard negatives, and any `--by` field):

- precision, recall and F1 of remove at the cutoffs 0.85, 0.60, 0.35 (the shipped Thumbnail presets and the earlier text presets) or `--cutoffs`, and the cutoff with the best F1 (0.01 steps). The shipped text presets are 0.90, 0.75, 0.55 (`src/core/verdict.ts` `STRENGTH_PRESETS`)
- ROC AUC, expected calibration error (10 equal bins) and Brier score of P(remove)
- rule attribution: share of true removes whose argmax Rule is one of the gold Rules, over all true removes and over Balanced true positives
- per Rule, at each cutoff: recall of the Tiles labelled with it (removed citing any Rule), removals citing it (argmax Rule), and the false removes among those (Tiles labelled keep)
- Keep questions (with `--keep`): precision, recall and F1 at pKeep 0.5, AUC, Keep attribution, and the final outcome at Balanced with the Keep override
- p50 and p95 latency per successful request, error rate and counts by HTTP status (every attempt), invalid answers
- cost: sum of `usage.cost`, cost per 1,000 Tiles, input tokens per Tile

Ambiguous Tiles are counted apart and never enter the headline numbers.
